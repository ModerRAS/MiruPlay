# Agent Docs

This directory is for agent-oriented project guidance that should not be inlined into `AGENTS.md`.

## What goes here
- Checklists the agent should follow for recurring project-specific tasks
- Small process notes that help keep cross-surface changes aligned
- Agent-facing guardrails with concrete file pointers

## What does not go here
- Product specs
- End-user documentation
- Broad architecture docs better placed elsewhere under `docs/`
- Temporary task notes or one-off session scratch files

## Usage
- Keep `AGENTS.md` short; link to files in this directory instead of pasting long instructions there.
- Prefer one focused document per recurring workflow or guardrail.
- Name files by the workflow or rule they describe, for example `settings-web-control-parity-checklist.md`.

## Current docs
- `settings-web-control-parity-checklist.md`: parity checklist for settings/menu changes across TV settings, WebAPI, and WebUI.
